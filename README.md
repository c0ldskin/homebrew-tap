# c0ldskin's Homebrew tap

Install [Zolt](https://github.com/c0ldskin/zolt-bot), the pixel desktop pet & AI voice assistant for macOS, or its Arabic-speaking sibling Zamil:

```bash
brew install --cask c0ldskin/tap/zolt
brew install --cask c0ldskin/tap/zamil
```

Both need macOS 26 or later and [Claude Code](https://claude.com/claude-code). See the [Zolt website](https://c0ldskin.github.io/zolt-bot/) for more.
